# v0.1.18 — Today shows only recent unfinished work

Today now applies a trailing 24-hour window to all unfinished approvals,
delegations and schedule activity. Finished and archived records are excluded,
including successful background checks. The Delivered section is removed from
Today; older records and results remain in their source modules.

Placeholder assignees are treated as unassigned. Archived approvals cannot reappear
as queued work. Approval recency respects recorded decision and execution times.
No task statuses are changed by this update. Both installer editions include it.
