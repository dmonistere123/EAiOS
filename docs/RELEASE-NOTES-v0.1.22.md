# 2EP by Allygnment — v0.1.22

Enhanced Executive Performance. An Executive AI Operating System.

EAiOS becomes **2EP by Allygnment**. The compact signature header places both
supporting lines to the right of the logo. The browser title and icon, application
help, new conversation labels and installer messages use the new name.

Fresh Core and Full installations include expandable **2EP**, **The App Stack**
and **Settings** menus, plus the orbital Staff page with Ally first and the human
assistant as the delegation backstop. The dark navy and cyan appearance remains.
Core continues to exclude Ticker; Full includes it. Existing module selections
are retained when updating.

This release preserves agents, profiles, custom instructions, credentials,
conversations, travel plans, approvals, human delegations and saved preferences.
Existing installation paths, service names and repository URLs remain compatible.
No data migration or agent/skill reinstallation is required. DCR remains in staging.

Existing machines: Settings → App Settings → Check for updates → Install update.
New machines can use the Core or Full installer pinned to v0.1.22 in INSTALL.md.
