# v0.1.19 — Visible human delegations and accurate calendar errors

The HI Assistant module now shows every open delegation directly beneath its
summary card, including the task title, assignee, instructions, due date, last
update, saved message and existing status actions. Older open delegations remain
visible here independently of Today’s 24-hour window. Finished delegations stay
in the assistant drawer’s history.

Today distinguishes calendar permission denials from authentication, rate-limit,
timeout and service failures. A failed provider request no longer tells the
executive to change calendar permissions without evidence of a denial.

Both installer editions include these changes. No delegation states, account
permissions, credentials or calendar sharing settings are changed.
