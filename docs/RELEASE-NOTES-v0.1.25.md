# 2EP by Allygnment — v0.1.25

The customer workspace is now named **E-CRM — Enhanced CRM**. Navigation, the page heading, import guidance and customer-facing messages use the new name.

This is a cosmetic update. Existing contacts, notes, saved links and workflows remain compatible. Full installations include E-CRM; Core keeps it optional. DCR remains excluded from general distribution.

Existing machines: Settings → App Settings → Check for updates → Install update.
