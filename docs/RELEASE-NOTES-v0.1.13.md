# EAiOS v0.1.13 — Executive Insights and core edition

## Included in this update

- Executive Insights is now a core module: top ten workflows, activity coverage, explicit recommendation generation, executive coaching habits and proposed success measures.
- Discuss with Ally opens an editable, unsent discussion prompt. Recommendations do not automatically install skills, create schedules, save preferences or send communications.
- Executive Leverage Score starts at “building your baseline.” Activity counts are not leadership scores or proven time savings.
- My Assistant expands the chat area, groups Telegram history by day, supports keyword/date search and opens recent messages. Telegram history is read-only.
- Live voice uses the existing Hermes configuration where supported. Work requests use the normal durable assistant and approval paths. Voice small-talk captions are temporary.
- Generic approved work routes through the default orchestrator without requiring an executor picker. Specialized communication approval controls remain in place.
- Separate core installer enables core modules with Social Media and Podcasts as optional additions. Existing installations retain the full module selection by default.

## Installation and preservation

Use the existing update screen or updater for deployed boxes. Do not run the core installer to convert an existing box. Agents, customized instructions, skills, credentials, conversations, schedules and application data remain in their existing locations. Routine updates do not install replacement agents or skills.

The core edition includes Today, My Assistant, Staff, Connections, Approvals, Schedule, Travel, Knowledge, Skills & Playbooks, Artifacts, Executive Insights, Usage, Backup and Settings. Usage remains included while its commercial role is evaluated.

Core and full editions share the application code and dependencies. Core controls which modules are enabled; this is not a separate security boundary or a marketplace for arbitrary plugins. Engineers implement custom modules separately and configure supported add-ons explicitly.

Recommendation generation requires an OpenRouter key and uses API credits only when requested. It sends aggregate activity categories and counts, not raw chats or email content. Recommendations are proposals and may require engineering work. Live voice requires a compatible, configured Hermes installation.
