# v0.1.17 — Today attention view

Today now counts real pending approvals, unfinished delegations, and unreviewed
schedule/results activity from the last 24 hours. Unassigned backlog is available
under Saved tasks instead of inflating Priorities. Reviewing a result clears its
priority across browsers while retaining delivery history.

Delegatable shows the latest saved Executive Insights recommendations. The agenda
shows the local day's meetings from verified connected Outlook accounts, including
completed meetings and per-account switches. Source failures are shown explicitly.

Both Core and Full include this Today update and the existing expandable navigation
and orbital Staff page. Core continues to exclude the ticker. Updates preserve
profiles, credentials, conversations, skills, module selections, and personal data.

See TODAY-DATA-SOURCES.md for source boundaries and per-box calendar selection.
