# Weekly Investor Update

Draft this week's investor update. DO NOT send anything — the executive
approves the final draft before any external write.

## Steps

1. Pull the week's metrics: new work completed (kanban done this week),
   cron job outcomes, and any notable agent activity from the activity ledger.
2. Draft the update in the house style: 3 sections (Wins, Numbers, Asks),
   under 400 words, plain confident tone, no hype.
3. Save the draft as an artifact and post it for executive review.
4. STOP. Sending to investors requires explicit executive approval through
   the EAiOS approvals queue.
